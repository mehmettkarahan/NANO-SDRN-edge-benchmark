# NANO-SDRN ablation study

The proposed **NANO-SDRN** is compared with a tri-scale-fusion reference. HDN, SR, SE and GAP-only component changes are evaluated **within the tri-scale reference**, not as individual removals from NANO-SDRN. All listed configurations were trained with seeds 42, 123 and 2026.

See `table_21_ablation.csv` for the published comparison and `results/` for component-level metrics, CV summaries and inference samples. The reference control remains explicitly labeled as such to avoid misinterpreting the ablation comparisons.
